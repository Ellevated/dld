## Что изменено 23.09, одной ночью

По решению Олега («на 5 версии дальше жить не будем») три правки катятся вместе, а не по
очереди, как планировали EXP-009 и EXP-010:

1. **Модель main loop — `claude-opus-5-5`** (`runner_models.DEFAULT_MAIN_MODEL`). Пин
   `ANTHROPIC_DEFAULT_OPUS_MODEL` идёт за ней, так что все агенты с `model: opus` (planner,
   review, debugger, персоны bughunt и council) тоже на 5.5. Sonnet и haiku не менялись.
2. **CLI на VPS 2.1.263 → 2.1.280.** Без этого переход невозможен: 2.1.263 отвечает
   `400 Claude Code 2.1.263 does not support this model; version 2.1.280 or newer is
   required`. Проверено пробой перед переключением, там же — что с 2.1.280 main loop и
   субагент `model: opus` оба отвечают из `claude-opus-5-5`. `_MIN_CLI_VERSION` поднят до
   2.1.280.
3. **Общие модули агентов в downstream-репо** — `output-conventions`, `search-cascade`,
   `minimal-code` вписаны в тела агентов (раньше `@`-строки до модели не доходили).
   Раскатка — `check-fleet-drift.py --apply-clean` плюс раскрытие оставшихся `@`-строк.

Системный промпт Claude Code вместо пустого (EXP-009) действует с 00:38 23.09 и в этот
замер входит.

## Граница среза

Прогоны, стартовавшие до переключения, идут на Opus 5 и в ночь на 23.09 перемешаны с
новыми. `--split 2026-09-23` их не отделит: в «после» брать только run-логи с
`"model": "claude-opus-5-5"`.

## Если не сработает

Три правки разом — значит, при просадке первым делом смотреть характер отказов, а не число:

- прогоны `exit 4` / `refusal.unrecovered > 0` → классификаторы 5.5 (`bio`,
  `reasoning_extraction` добавились к `cyber`), разбирать по `refusal.categories`;
- спеки встают на `needs_review` / `branch_pushed_not_merged`, в result_text отказ
  коммитить или пушить → системный промпт Claude Code спорит со скиллом:
  `AUTOPILOT_SYSTEM_PROMPT=empty` в `scripts/vps/.env`;
- таймауты с длинными ходами без коммитов → 5.5 на `medium` думает дольше, чем Opus 5
  на том же уровне: сначала `AUTOPILOT_EFFORT=low`, а не откат модели;
- ничего из этого не видно, а метрики хуже порога → `AUTOPILOT_MODEL=claude-opus-5`
  (пин opus идёт за ним), CLI 2.1.280 работает и с Opus 5.

Все три рычага в `.env` читаются `run-agent.sh` на каждый прогон, рестарт демона не нужен.
