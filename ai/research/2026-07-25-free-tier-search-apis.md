# Free-tier поисковые API: аналоги Exa и система на бесплатных ярусах

> **Дата снапшота:** 2026-07-25. Цены и лимиты поисковых API меняются часто — перед внедрением сверить с актуальными страницами (ссылки в конце).
> **Контекст:** нужен веб-поиск для агентов/дев-задач с минимальной или нулевой стоимостью. Профиль потребления — лёгкий («не много пользуюсь поиском»).

---

## TL;DR

1. **У Exa есть постоянный free tier** — ~1,000 запросов/мес + ~$10 стартовых кредитов, карта не нужна, лимит обновляется каждый календарный месяц. Для лёгкого юзера этого хватает с запасом.
2. **Ротация клонов одного сервиса — антипаттерн.** Нарушает ToS (риск бана всех аккаунтов), хрупко. Живой урок 2026: Brave убил бесплатный tier и начал списывать деньги с ранее привязанных карт.
3. **Правильная система — каскад из 2-3 РАЗНЫХ провайдеров**, у каждого свой честный free tier. Легально, устойчиво, суммарный лимит в разы выше клонов.
4. **Два слоя уже бесплатны и без аккаунтов:** встроенный WebSearch в Claude Code и Jina `s.jina.ai` (без ключа).

## Сравнение free tier (июль 2026)

| Провайдер | Free tier | Тип | Карта | Чем полезен |
|---|---|---|---|---|
| **Exa** | ~1,000 запросов/мес (+~$10 стартовых кредитов) | постоянный, обновляется помесячно | не нужна | семантический поиск + полный контент страниц |
| **Jina** `s.jina.ai` | практически безлимит без ключа (rate limit ~20 запр/мин) | постоянный | не нужна | **лучший fallback** — поиск + чтение страниц вообще без аккаунта |
| **Claude Code WebSearch** | встроен в CLI | постоянный | — | уже доступен, 0 аккаунтов, 0 стоимости |
| **Google Programmable Search** | 100 запросов/день (~3,000/мес) | постоянный | нужна для получения API-ключа (не биллит) | классический Google-индекс |
| **Tavily** | 1,000 кредитов/мес (базовый поиск = 1 кредит) | постоянный | не нужна | заточен под AI-агентов |
| **You.com** | ~60 запросов/день (~1,800/мес) | постоянный | — | web search API |
| **Serper** | 2,500 запросов | **одноразово** (не помесячно) | не нужна | Google-выдача как JSON, дёшево дальше ($0.30–1/1k) |
| **SearXNG** | безлимит (self-host) | постоянный | — | свой мета-поисковик, платишь только за VPS (~$5/мес) или локально бесплатно |
| **SerpAPI** | 100 запросов/мес | постоянный | не нужна | много движков, но лимит маленький |
| **Firecrawl** | 500 кредитов | одноразово (trial) | нужна | search + extract, скорее для скрейпа |
| **Brave Search API** | ⚠️ **free tier убран в 2026, сохранённые карты биллятся** | — | нужна | **не рекомендуется** |

### Нюансы кредитных моделей
- **Tavily:** базовый поиск = 1 кредит, advanced = 2, а Research-вызов может сжечь 4–250 кредитов. 1,000 кредитов ≠ 1,000 сложных запросов.
- **Exa:** pure usage-based поверх баланса кредитов. Standard Search ~$7/1k, Contents ~$1/1k страниц (после исчерпания бесплатного).
- **Serper 2,500** — это ОДНОРАЗОВЫЙ пул на аккаунт, не помесячный. Единственный кандидат, где ротация аккаунтов реально что-то даёт (но см. про ToS-риск).

## Предлагаемая система: каскад free-провайдеров

Не «3 клона Exa», а fallback-каскад разных провайдеров — по образцу существующего `job-search/scripts/lib/llm.js` (Claude → OpenCode Go):

```
Слой 0:  Claude Code WebSearch (встроенный)   → быстрые факты, 0 аккаунтов, 0 квоты
   ↓ (нужна семантика / полный текст страницы)
Слой 1:  Exa free tier (~1,000/мес)            → основной семантический поиск
   ↓ (лимит исчерпан / ошибка)
Слой 2:  Jina s.jina.ai (без ключа)            → fallback поиск + чтение страниц
   +
Кэш:     локальный кэш ответов по URL/запросу  → повторы не жгут квоту (как делает сама Jina)
```

**Суммарный легальный лимит без единой карты и без клонов:** Exa 1,000 + Tavily 1,000 + Google 3,000/мес + You.com 1,800 + Jina/WebSearch безлимит ≈ **6,000–7,000+ запросов/мес**. Для лёгкого потребления — потолок в 5–10 раз выше реальной нужды.

### Почему не ротация клонов
- ToS почти всех провайдеров запрещает multi-account для обхода лимитов → бан пачкой.
- Хрупкость: провайдер меняет правила — схема рушится (кейс Brave 2026).
- Комбинация разных провайдеров даёт больше лимита И устойчивее.

## Варианты реализации (развилка)

| Вариант | Что делаем | Когда |
|---|---|---|
| **A. В чате Claude Code** | Настроить бесплатные MCP-провайдеры + встроенный WebSearch как основной, Exa/Jina как усиление. Только конфиг, без кода. | если поиск нужен интерактивно через Claude |
| **B. В скриптах** | Написать обёртку `search.js` с fallback-каскадом Exa→Jina→кэш, ключи через `.env`/Nexus. По образцу `llm.js`. | если поиск нужен в автоматизации (job-search и т.п.) |
| **C. Оба** | MCP для чата + `search.js` для скриптов, общий пул ключей, единая логика fallback. | если нужно и то, и другое |
