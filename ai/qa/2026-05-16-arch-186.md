**User impact:**

- **Founder теряет доверие к callback gate.** P0/R1 spec помечен «сделано», когда ни один файл не создан. Это означает, что любая авто-доска статусов в DLD сейчас может врать.
- **Hermes/Telegram бридж покажет «ARCH-186 done»** в queries → founder читает «done», думает что lifecycle migration уже на проде, не запускает реальный autopilot. Дальнейшие BUG-185-style race-condition'ы остаются в продакшене.
- **Orchestrator при следующем cycle callback'а может перезаписать ручной revert** (callback — ADR-018 sole writer; `_resync_backlog_to_spec` будет пытаться выровнять Status `done` обратно). Founder придётся снова чинить руками — и так до тех пор пока guard не починят.
- **ACTION REQUIRED protocol сломан.** Spec прямо говорит «Не auto-handoff. Никаких exceptions» — но guard всё равно решил, что задача сделана, без какого-либо human review.

**Hint for developers:**

Симптом матчит ранее описанный паттерн в `project_callback-false-done-pattern.md`. Гипотеза корневой причины (требует подтверждения через `scripts/vps/audit-logs/` если они генерируются для verify_status_sync):

- `_spec_has_merged_implementation` использует `git log --all --grep=<spec_id> -- <allowed_files>`.
- В `Allowed Files` для ARCH-186 указан **`ai/backlog.md`** (т.к. он становится auto-rendered).
- Renumbering commit `f41903f` упоминает «ARCH-186» в message **и** трогает `ai/backlog.md` (массовое переименование таблицы).
- Guard видит: «есть merged commit с grep-hit на ARCH-186 на allowed-файле» → решает что implementation merged → автозакрывает.
- Это новый класс false-positive: **docs/rename коммиты не должны считаться implementation evidence**, особенно когда trigger-file — это auto-rendered view (`backlog.md`) или сама spec.

Возможные направления фикса (на чойс архитектора, не QA):
1. Исключить из `<allowed_files>` для guard'а: `ai/backlog.md`, `ai/features/*.md` (они мутируются rename/auto-render, не «implementation»).
2. Требовать, чтобы матчящий коммит содержал change хотя бы в одном из NEW/MODIFY файлов категории `scripts/`, `src/`, `tests/`.
3. Сравнивать `git diff --stat` коммита с whitelist «implementation paths» — docs-only коммиты не считать.
4. Уважать ACTION REQUIRED маркер — если spec содержит `ACTION REQUIRED: HUMAN REVIEW BEFORE AUTOPILOT`, guard вообще не должен трогать Status (только human через `spec_operator.py demote/done`).
