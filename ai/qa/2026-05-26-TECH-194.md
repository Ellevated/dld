### F1: Layer C end-to-end НЕ работает в awardybot worktree (CRITICAL)

**Severity:** Critical
**Reproducibility:** Always
**Expected:** Direct `git commit ai/lifecycle/<spec>.yaml` из любого worktree любого orchestrator-проекта → rejected hook'ом с сообщением `pre-commit-lifecycle-guard`.
**Actual:** В worktree awardybot коммит прошёл с exit 0 (commit `e5deeb3d` создан, потом откатил).

**Steps to reproduce:**
```bash
cd /home/dld/projects/awardybot
git worktree add -b qa-test/hook /tmp/wt
cd /tmp/wt
mkdir -p ai/lifecycle && echo "status: done" > ai/lifecycle/QA-TEST.yaml
git add ai/lifecycle/QA-TEST.yaml
git commit -m "should be blocked"
# → [qa-test/hook e5deeb3d] should be blocked
# → exit code: 0
```

**Evidence:**
- `git config core.hooksPath` = `.git-hooks` (relative) — C1 fix не дошёл до awardybot
- `grep "git-common-dir" awardybot/.git-hooks/pre-commit` = 0 — C2 fix не дошёл
- `grep "import.meta.url" awardybot/.claude/hooks/pre-commit-lifecycle-guard.mjs` = 0 — C3 fix не дошёл

**User impact:** Точно тот же сценарий S1 из спеки (awardybot:BUG-1075 direct commit с `updated_by: autopilot`) остаётся возможным. ADR-025 SoT invariant нарушаем напрямую через `git commit` в worktree autopilot'а. TECH-194 декларировал закрытие — закрыто только в dld repo.

**Hint:** Layer C изменения лежат в template/ + dld/.claude/, но `/upgrade` — ручной cherry-pick (см. `.claude/skills/upgrade/SKILL.md`). Нужен sync awardybot/dowry/wb (мин. 3 проекта где наблюдались симптомы) + запуск `scripts/vps/install-hooks-all-worktrees.sh` поверх — этот тулинг существует и работает, но не запускался по проектам.
