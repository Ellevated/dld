## Failures

### F1: Existing callback test regression — `_append_blocked_reason` no longer writes spec

**Severity:** Major
**Reproducibility:** Always
**Expected:** After callback dispatches `blocked` for a non-done spec, the spec file contains `**Status:** blocked` (existing contract from `test_blocked_target_still_writes_when_spec_not_done`).
**Actual:** Spec stays at `**Status:** in_progress` — Task 2's rewrite of `_append_blocked_reason` routes the write through `_git_commit_push` + `_read_head_blob`, which silently returns False in the test environment (tmp dir has `.git/` and `ai/features/`, but the spec file is not committed to HEAD, so `_read_head_blob` returns None → function logs a warning and exits without mutating the spec).

**Steps to reproduce:**
```bash
cd /home/dld/projects/dld
python3 -m pytest scripts/vps/tests/test_callback.py::TestBlockedOverDoneGuard::test_blocked_target_still_writes_when_spec_not_done -v
```
**Evidence:**
```
AssertionError: assert '**Status:** blocked' in '# BUG-3\n\n**Status:** in_progress\n'
```
**Pre-existing check:** Same test passes on parent commit `8975438` (before TECH-182), so this is a real regression introduced by Task 2.

**User impact (operator):** In production, `_append_blocked_reason` writes the spec only if it exists at HEAD. If a brand-new spec hasn't been committed yet (e.g. just landed via merge race), the `blocked` reason silently gets dropped. The spec's `verify_status_sync` may still flip the status header via the separate plumbing path, but the **Blocked Reason: ...** rationale line — the operator-facing diagnostic — is lost.

**Hint for developers:** Spec acceptance criterion explicitly flagged this: "Existing `tests/test_callback.py` either passes unchanged or is updated in a follow-up task with operator approval." That follow-up never happened. Either (a) update the test to seed the spec into HEAD via `git add+commit` in `tmp_path`, or (b) make `_append_blocked_reason` fall back to working-tree read when HEAD has no copy (only the write side needs to go through plumbing).
