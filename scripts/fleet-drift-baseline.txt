# Fleet drift register — scripts/check-fleet-drift.py
#
# One line per downstream project: how many synced files may differ from `template/`
# before the gate fails. Same contract as `scripts/vps/loc-limit-baseline.txt` — the
# gate fails on a project that got WORSE than its entry, never on the history.
#
# **These numbers changed meaning on 2026-08-31.** They started as raw damage: ~95
# diverged files per project after three months of hand-copying. Then every drifted
# file was checked against the full history of `template/` in git, which answers the
# only question that matters — is this content something template once shipped, or
# something the project wrote itself?
#
#   805 drifted files  ->  720 pure snapshots (dated Jan..Aug, nobody's work)
#                          85 holding real local edits
#
# The 720 were refreshed (`--apply-clean`); the 85 were left alone. So what these
# numbers now count is **deliberate project-specific content**, not neglect:
#
#   AwardyBot   session-end.mjs guard against losing an autopilot worktree (three runs
#               died that way on the night of 2026-08-21, $58.80 of finished work);
#               check_domain_imports/check_docs_sync rewritten for its own bots/+agents/
#               layering; validate-blueprint-compliance with a domain-token normaliser;
#               pre-edit.mjs LOC exemptions for prose; local-Spark SSH claim protocol
#   PLPilot     review.md section 3.6 — mutation proof for security/money invariants,
#               wired to its own scripts/fitness/ and scripts/mutation/ registry
#   Dowry       seed-lessons extended to FTR/TECH/ARCH (the file says so in a comment)
#   Dowry-mc    autopilot with the spec-reviewer folded inline
#   gipotenuza  coder.md pointing at .claude/rules/domains/{domain}.md for history
#
# **MishkinLyap is at 0** and carries a stamped `.claude/DLD_VERSION`. That is what the
# end state looks like: the marker is only written when a project actually reaches this
# template version, and it is re-verified from disk on every run.
#
# Raising a number is an admission that a project drifted further — say why in a
# comment. Lowering one means real convergence. To see what a project still holds:
#
#     python scripts/check-fleet-drift.py D:/dev/<project> --json
#     python scripts/check-fleet-drift.py D:/dev/<project> --apply-clean   # safe refresh
#
# `--apply` (overwrite everything) stays a per-file human decision. It is the mode
# that got `upgrade.mjs` deleted on 2026-05-25.

AwardyBot   = 35
